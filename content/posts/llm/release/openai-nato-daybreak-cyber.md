OpenAI（**2026-11-17**）发文说明经 **Daybreak** 把先进 AI 交给受信防御方做授权安全工作：审软件、查可疑活动、验证漏洞并开发/测试修复。与北约通信与信息局（**NCIA**）合作，为北约核心机构提供网络安全模型；文称北约相关用量最高约每月 **3000 亿**原始输入输出 token。

另支持北约 CCDCOE **2026 Crossed Swords** 演习中新建的 AI Agent 训练流，强调人在环。盟国侧列举欧盟 **ENISA**（称用模型发现并推动修复四项机构软件漏洞，另有与 CERT-EU 联合报告）、乌克兰数字转型部民用基础设施、**CERT Polska** 与 MikroTik RouterOS 漏洞披露等。属**政策/合作通稿**，非通用 API 功能发版；能力边界以 Daybreak 授权范围为准。

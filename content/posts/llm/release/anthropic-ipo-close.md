Anthropic（**2026-11-20**）宣布首次公开发行**交割完成**，承销商超额配售期权**全额行使**。本稿记交割与开盘节点；路演与定价细节见站内前序稿。

## IPO 结构（公司通稿）

| 项 | 数字 |
| --- | --- |
| 发售总量 | 约 **11.27 亿**股 A 类（含超额配售约 **1.47 亿**股） |
| 公开发行价 | **83.00** 美元/股 |
| 公司出售 | 约 **11.0335** 亿股 |
| 现有股东出售 | 约 **2365** 万股（公司不获该部分款项） |
| 发行毛额（扣费前） | 约 **935** 亿美元 |
| 公司所得（扣费前口径） | 约 **916** 亿美元 |

A 类股自 **2026-11-19** 起在纳斯达克 Global Select 以 **ANT** 交易。登记声明于 **11-18** 生效。

## 并行私募

向 AMD、Broadcom、Google、Micron、Microsoft、NVIDIA、TSMC Partners 等合计约 **3.1325** 亿股 **Class N**，同价 **83.00** 美元，总额约 **260** 亿美元；未按《证券法》登记。IPO（含股东出售）与私募合计毛收入约 **1195** 亿美元（扣费前）。

主承销：Goldman Sachs、Morgan Stanley；另有多家 book-runner / co-manager（名单见通稿）。数字均来自公司公告，非第三方估值。

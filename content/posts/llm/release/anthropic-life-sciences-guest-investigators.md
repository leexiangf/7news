Anthropic 向生命科学领域公开征集 guest investigators（客座研究员）。欢迎学术机构、非营利组织或政府实验室的首席研究员（PI）及其团队提交提案，与公司研究员一起做专项课题。官方列出的方向示例包括因果人类生物学、结构与计算分子生物学、药物化学、药物发现和临床科学。提案通过官方页面提交。

合作形态比发放 API Key 更重。官方写明周期约 8 到 12 周。Anthropic 团队免费运行其模型与 harness。双方共同产出分析、工件与工具，并计划公开发布，同时开源配套数据与代码。权益边界也写进了公告：客座方在项目全程保留自身数据权利，并对协作衍生的独立后续研究保留权利。

可以把这件事读成「用真实课题反哺模型与工作流」。问题仍由一线科学方提出；公司侧提供算力和 Agent 运行时。对关注 AI4Science 的工程读者，短期价值往往不在口号，而在项目结束后可能公开的数据结构、工具形态和可复现流程。申请截止日、评审标准和录取规模，目前以官方征集页与表单为准；本文不作额外承诺。

商汤英文新闻宣布多模态 Agent 模型 **SenseNova 6.8 Flash** 正式版上线，面向办公智能与复杂任务：强调**长时记忆、主动交互与跨任务协作**，并在客户跟进、员工交接等演示中说明如何用历史上下文做提醒与材料整理。

设计侧，生成从静态材料扩展到动态/交互：动态 PPT、动画海报、Blender 三维与动画、Web/SVG、Three.js 交互页，并可对接 Figma 等工作流；三维相关能力需本地环境与多轮交互。文中称在 Agent 协作、数据分析与演示生成等任务上表现强，并「在多项基准上超过部分国际领先模型」——属厂商表述，本稿不展开未公布的逐项分数。

试用：经 SenseNova Token Plan 申请 API key，英文稿写明每 5 小时最多 **1500** 次免费请求（[platform.sensenova.ai](https://platform.sensenova.ai/)）。

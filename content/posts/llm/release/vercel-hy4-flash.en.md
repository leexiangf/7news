Vercel’s Changelog (**16 Nov 2026**) adds Tencent’s **Hy4 Flash** to **AI Gateway** as `tencent/hy4-flash`. It is framed as the lower-cost Hy4 sibling that keeps the full feature set at roughly a **tenth** of the token price—reasoning with preserved thinking across turns (disable when unused), tool calling, structured outputs, prompt caching, image input, and a **1M**-token context—aimed at high-volume coding, agent, and document work.

Through **29 Nov 2026**, input, cached input, and output tokens are **50% off**. Call it via the AI SDK, fx, Chat Completions, or `npx vercel ai-gateway setup` for coding agents. This is a **Gateway availability + promo** note; model cards and list prices remain with Tencent and the Gateway pricing page.

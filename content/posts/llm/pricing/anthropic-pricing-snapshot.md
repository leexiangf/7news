Anthropic **Claude 定价页**同时展示消费套餐与 Claude Platform（API）计价。选型时务必把「聊天 / Claude Code 套餐」与「API token 价」分开建模——同一页、两套账。

## 个人档（页面公开价）

| 档 | 标价 | 用量口径（文案） |
| --- | --- | --- |
| Free | $0 | 每 5 小时与每周有限用量 |
| Pro | 年付约 **$17**/月（预付 $200）或月付 **$20** | 相对 Free 更多；含 Claude Code、Projects 等 |
| Max | **$100**/月 | 约 **5×** Pro（5 小时窗与周额度）；含每月 **$100** API 额度 |
| Ultra | **$200**/月 | 约 **10×** Pro 周额度；验证账户**无 5 小时限制**；每月 **$200** API 额度 |

价格不含税；Anthropic 可调整。Team / Enterprise 另有席位与销售定制（Enterprise 文案可见约 **$20**/席位·月 + API 用量等表述）。

## API 侧（同页摘录）

页面另列当前代模型输入 / 输出 / prompt caching 单价（单位 $/MTok），以及 Managed Agents 会话时、Web search、Code execution 等附加费。Legacy 模型价表亦在同页。引用具体模型单价时打开实时页——产品代际名称与数字会变。

续费或对账前：Settings > Usage 看窗口用量；API 侧用 Console 价表，勿与 Pro/Max 席位混算。

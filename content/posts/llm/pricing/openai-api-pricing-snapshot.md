OpenAI **Business Pricing** 页集中展示面向企业与商业计划的入口，同时承担 ChatGPT Work / Codex 与 API 额度导航。本稿整理公开结构，**不是**涨价通告；美元席位价以页面卡片实时数字为准。

## 两档怎么读

| 计划 | 公开口径 |
| --- | --- |
| **Business** | 安全工作区；可混搭席位；接 Google Workspace / Slack / GitHub / M365 等；SAML / SSO / MFA；集中计费与用量控制；默认可不训练业务数据；工作区 Agent；文案称工作区最高约 **$500**/月 API 额度 |
| **Enterprise** | 销售定制价；扩展上下文；SCIM、EKM、RBAC、数据驻留（文称十个区域）、SLA / 法务条款等 |

FAQ：个人档另有 Free / Go / Plus；教育与非营利另有折扣入口。文称自 **12 月**起计划用量将在 ChatGPT 与 Codex 间**共享限额**——部署前核对「Learn more」链接。

## 建模建议

把**席位费**与 **API / 额度消耗**拆成两条线；Business 与 Enterprise 均可另购额度扩大访问。模型名（GPT-6.x Sol / Astra 等）与上下文窗口数字会随产品更新——引用时打开实时对照表，勿用缓存截图做合同附件。

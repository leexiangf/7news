Anthropic’s **Claude pricing page** shows consumer plans and Claude Platform (API) rates together. Model seat/chat plans and API token prices as **two ledgers**—same page, different bills.

## Individual plans (published prices)

| Plan | Price | Usage framing (copy) |
| --- | --- | --- |
| Free | $0 | Limited every 5 hours and every week |
| Pro | ~**$17**/mo annual ($200 upfront) or **$20** monthly | More than Free; Claude Code, Projects, and peers |
| Max | **$100**/mo | ~**5×** Pro (5-hour and weekly); **$100**/mo API credits |
| Ultra | **$200**/mo | ~**10×** Pro weekly; verified accounts **no 5-hour limit**; **$200**/mo API credits |

Taxes not included; Anthropic may change plans. Team / Enterprise add seats and sales-assisted options (Enterprise copy cites ~**$20**/seat/month plus API usage).

## API side (same page)

The page also lists current-generation input / output / prompt-caching rates ($/MTok), plus Managed Agents session-hours, web search, code execution, and legacy model tables. Cite specific model rates from the live page—names and numbers move with generations.

Before renew or reconcile: Settings > Usage for plan windows; Console rates for API—do not mix Pro/Max seats into token math.

GitHub Changelog 宣布：**GitHub Copilot** 现可直接接入 **Xcode 内置 coding assistant**，状态为公开预览，自 **Xcode 27.3 beta** 起可用。这是相对「独立扩展」之外的另一条原生工作流；既有 **Copilot for Xcode** 扩展仍然保留，可按习惯二选一。

环境要求：从 Apple Developer Downloads 取得 Xcode 27.3 beta，Mac 需 **macOS Tahoe 26.6+**。在 **Xcode > Settings > Intelligence** 配置 Copilot；官方称各 Copilot 方案均支持。反馈可走 Copilot for Xcode 仓库或 Apple Feedback Assistant。

GitHub Changelog（**2026-11-18**）宣布 **Team customizations** 对组织团队 **GA**：团队 maintainer / 组织 owner 可在团队页 **Customize Copilot** 中，把批准的 **Agent Plugins** 设为团队默认（来自内置、企业或团队添加的 marketplace）。

所选插件对团队**直接成员**在 VS Code、GitHub Copilot 应用与 Copilot CLI 中默认启用；子团队成员不继承。成员可在策略允许下关闭团队插件。企业与组织策略仍优先（允许的 marketplace、必装/封禁插件）。面向 **Copilot Business / Enterprise**。属**团队配置**短讯。

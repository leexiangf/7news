Cursor Changelog 宣布可与 Agent 进行**实时语音通话**：口述要改什么、询问 Agent 正在做什么，并听进度更新。入口覆盖 **Agents Window、IDE、Web、iOS**。

当 Agent 空闲且聊天输入为空时，可点波形按钮 **Start voice chat**（通常在 Send 位置旁）。iOS 还可说 “Hey Siri, call Cursor” 拉起新 Agent 通话，并在锁屏 Live Activity 上静音或挂断。

对习惯键鼠的开发者：这是交互通道更新；权限、地区与配额以 Cursor 订阅说明为准。

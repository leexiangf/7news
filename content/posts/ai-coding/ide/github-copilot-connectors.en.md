GitHub’s changelog adds connectors for **Supabase, Box, Calendly**, and more to Copilot. Examples: ask why the latest Buildkite build failed and fix code in the same session, or inspect a Supabase schema before writing a migration. Connect once and reuse across Copilot.

Availability: **public preview** for all Copilot plans. Business/Enterprise admins must enable **Editor preview features**; if the MCP allowlist enumerates connectors, add the new ones; some services also need admin enablement on their side (e.g., Box MCP).

Admins should align preview policy and allowlists before rolling out to developers.

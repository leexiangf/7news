GitHub’s Changelog says **GitHub Copilot** now works inside **Xcode’s built-in coding assistant** in public preview, starting with **Xcode 27.3 beta**. It is an additional native path alongside the existing **Copilot for Xcode** extension—you can keep using either workflow.

Requirements: download Xcode 27.3 beta from Apple Developer Downloads on a Mac running **macOS Tahoe 26.6+**. Configure Copilot under **Xcode > Settings > Intelligence**. All Copilot plans are supported. Feedback routes through the Copilot for Xcode repo or Apple Feedback Assistant.

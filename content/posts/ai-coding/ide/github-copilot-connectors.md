GitHub Changelog 宣布可为 Copilot 连接 **Supabase、Box、Calendly** 等更多服务。示例包括追问最新 Buildkite 构建为何失败并在同会话修代码，或先检查 Supabase schema 再写迁移；连接一次即可在 Copilot 中复用。

可用性：**公开预览**，覆盖各 Copilot 计划。Business / Enterprise 需管理员打开 **Editor preview features**；若企业 MCP 允许列表是逐项而非通配，还需加入新连接器；部分服务（如 Box MCP）还要在服务方开启。

对企业管理员：先核对预览策略与允许列表，再向开发者放开。

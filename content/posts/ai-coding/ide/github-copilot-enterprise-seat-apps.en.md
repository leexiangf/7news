GitHub’s Changelog says **Enterprise GitHub Apps** can now call the enterprise-level **Copilot seat management APIs** to control which users and enterprise teams get Copilot seats. Access uses a new enterprise fine-grained App permission: **Enterprise Copilot license management**. Aimed at enterprises that want seat assignment automated through internal identity or procurement flows.

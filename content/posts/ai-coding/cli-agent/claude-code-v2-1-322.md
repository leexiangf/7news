Claude Code 发布 **v2.1.322**。公开发布说明仅一条：在 **Vertex** 的 **global、us、eu** 区域启用 **fast mode**；若 Vertex 拒绝该模式，则回退标准速度。面向走 Google Cloud Vertex 路由的用户，属区域可用性补丁而非功能大版本。

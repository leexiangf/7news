Microsoft Foundry 博客（**2026-11-18**）把 **Toolboxes** 定位为跨 Agent 舰队的共享能力层：在 Foundry 策展并版本化工具、技能与 Agent，经**一个 MCP 端点**暴露，集中下游鉴权，并用 tool search 按需发现以免撑爆上下文。

Ignite 增强摘录：Skills CRUD API（即将 GA）与 Shell 执行技能（预览）；**Web Search** 由 Web IQ 驱动（prompt agent GA，Toolbox 即将跟进）；Fabric IQ / Work IQ 预览增强；**A2A** 工具 GA；目录新增 Snowflake、MongoDB、Databricks；Copilot 一键装 Toolbox；监控看板与工具策略预览；**浏览器自动化**与 **Computer Use**（Astra 系）GA。属 **Ignite 工具生态**专稿，各能力状态以控制台为准。

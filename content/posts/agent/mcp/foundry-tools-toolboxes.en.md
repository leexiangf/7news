Microsoft’s Foundry Blog (**18 Nov 2026**) frames **Toolboxes** as shared capabilities for an agent fleet: curate and version tools, skills, and agents in Foundry, expose them through **one MCP endpoint**, centralize downstream auth, and use tool search so catalogs grow without stuffing every definition into context.

Ignite highlights include Skills CRUD (GA coming soon) and Shell-based skill execution (preview); **Web Search** powered by Web IQ (GA on prompt agents, Toolbox soon); Fabric IQ / Work IQ preview upgrades; **A2A** tool GA; Snowflake, MongoDB, and Databricks in the catalog; one-click Toolbox install in Copilot; a monitor dashboard and preview tool policy; plus **browser automation** and **Computer Use** (Astra-class models) at GA. Ignite tools ecosystem piece—check the console for each capability’s exact state.

腾讯云开发者社区发布「MCP广场开源版权声明」：相关文章由作者授权社区发表，**未经许可不得转载**，并附腾讯云版权信息。

## 怎么读这篇

| 是 | 不是 |
| --- | --- |
| 授权与转载边界说明 | 新 MCP 服务器 / SDK 上线公告 |
| 二次分发前的合规提醒 | 协议版本或目录变更清单 |

对集成或镜像 MCP 广场资料的团队：先确认授权范围，再决定引用、镜像或改编。功能目录、协议与 SDK 变更仍回腾讯云 MCP 广场产品与文档入口——本说明本身不是功能上新。

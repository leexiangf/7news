Tencent Cloud’s developer community posted an “MCP Square open-source copyright notice”: related articles are published with author authorization, **may not be reprinted without permission**, and carry Tencent Cloud copyright language.

## How to read it

| Is | Is not |
| --- | --- |
| Authorization and reprint boundary | New MCP server / SDK launch |
| Compliance reminder before redistribution | Protocol or catalog changelog |

Teams integrating or mirroring MCP Square materials should confirm authorization scope before citing, mirroring, or adapting. Feature catalogs, protocols, and SDKs still live on Tencent Cloud MCP Square product and docs pages—this notice itself is not a capability ship.

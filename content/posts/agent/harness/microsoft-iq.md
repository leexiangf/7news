Microsoft Azure 博客（Yitzhak Kesselman，**2026-11-17**）宣布 **Microsoft IQ**：面向企业的**上下文管理平台**，把 **Work IQ、Fabric IQ、Foundry IQ、Web IQ** 与 **350+** 第三方连接器收成一套可策展、可治理的「组织智商」，主张优势在模型之外的流程、制度知识与系统记录数据。

新增 **业务插件（business plugins）**：把上下文、技能与权威源打成可复用包，供 Microsoft Copilot、GitHub Copilot、Foundry（经 MCP）以及 ChatGPT / Claude 市集等侧的 Agent 继承。同日要点摘录：Work IQ 的 Business Applications / Retrieve / 实时会议上下文等 GA；Foundry IQ 知识图谱与 **Microsoft Retriever 1** 预览，**Foundry IQ Serverless** 称 **2026-12** GA；**Web IQ** 对全体 Azure 客户开放、无候补，定价起自约 **$1 / 千次**调用，并加 Places/Weather、Scopes、BYOL 等。客户案例点到澳大利亚 **AEMO** 的 NEM-GEM。属 **Ignite 平台叙事**；各子能力 GA/预览以分篇博客为准。
